Sobre o Projeto

O projeto Fazbear Archives foi desenvolvido como um site temático utilizando Bootstrap 5 como principal ferramenta de estilização, responsividade e organização do layout.

Tema escolhido

O tema escolhido foi Five Nights at Freddy's, uma franquia de terror com animatronics, câmeras de segurança, pizzaria abandonada e suspense noturno.

Objetivo

Criar um site responsivo com múltiplas páginas, componentes do Bootstrap e uma experiência visual coerente com o tema escolhido.

Componentes Bootstrap usados

A barra de navegação conecta as três páginas e o dropdown leva diretamente aos personagens.

O carousel da página inicial possui três imagens, indicadores e botões de navegação.

O projeto usa modal para ficha de personagem, collapse para relatório, offcanvas para dicas e cards para organizar informações dos animatronics.

Estrutura do Projeto

  • index.html: página inicial com carousel, cards, modal e seção flex.
  • animatronics.html: catálogo dos personagens com cards e tabela.
  • sobre.html: explicação do projeto e componentes usados.
  • css/style.css: arquivo de personalização visual.
  • img/: imagens SVG usadas no carousel e nos cards.
